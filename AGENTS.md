# Dirpick

Dirpick is a standalone Rust terminal application for filesystem navigation,
file, directory, and content search, filename filtering, and source previews.

## Agent skills

### Issue tracker

Specs and tickets use GitHub Issues in `vimkim/dirpick`.
Read `docs/agents/issue-tracker.md` before tracker operations.

### Triage labels

Read `docs/agents/triage-labels.md` before applying triage labels.

### Domain docs

This repository has one domain context.
Read `docs/agents/domain.md` before domain exploration or design.

## Working environment

Development runs on a remote Linux host. Use terminal tools and headless checks.
Disable browser auto-opening.
